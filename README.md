A one-line out-of-office auto-reply that reads like a real message a person would actually switch on before going away — and still makes a colleague laugh. The program validates the line and writes it to `entry.txt`.

> I'm out of office until Monday — my inbox is being guarded by an intern who has never met me and is already afraid of you.

## Run it

```bash
node main.ts
```

This writes the entry line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
